## What is protected

For a date with a seven-style FLUX \`style_id\`, the read-only check
\`scripts/zodiac_publish_guard.py\` must pass before (1) moving assets to
public GitHub raw hosting, (2) YouTube upload, (3) Threads carousel/reel
publication and (4) Instagram carousel or A/B video publication.
A stored pre-existing MP4 is **not** grandfathered in. Every A/B video must
have its own SHA-256 in the signed review. The public CDN bytes must match
those approved SHA-256 values. Failed status prevents external post calls.
Legacy unstyled dates retain the previous policy.

## Required independent review, not yet granted

Seven source atlases currently remain \`PENDING_QA\`, formal GitHub PR

No assistant-authored QA report or local test is evidence that these release

rewrite the source manifest to PASS, or lower test thresholds.

For future externally approved releases, a separate authorized reviewer
must inspect **all** relevant animal portraits, final cards and completed
narrated videos and establish the correct M/F Hanbok, animal/caption geometry,
independent ASR or equivalent voice-to-scene validation, and code review.
Only that independently approved reviewer may authorize a date-scoped
\`assets/zodiac_release_approvals/YYYY-MM-DD.json\`:

- \`schema\`: \`zodiac-signed-release-v1\`
- \`status\`: \`APPROVED\`
- \`date\`, \`style_id\`, \`scopes\` (\`cards\`, \`video\`), \`reviewer_id\`,
  timezone-aware \`approved_at\`.
- \`source_manifest_sha256\` and \`atlas_manifest_sha256\` binding the
  actual independent verification evidence.
- \`cards_sha256\`: all six JPEG file basenames to exact hashes.
- \`videos_sha256\`: each completed full voiced MP4 including A/B variants.
- \`avatar_and_voice_qa_status\`: \`PASS\` only after real video and
  gender/voice review, not from generated-source success.
- \`hmac_sha256\`: HMAC-SHA256 of the JSON fields excluding the signature,
  with UTF-8 / sorted keys / compact separators / ensure_ascii=False.

The key name is \`ZODIAC_RELEASE_REVIEW_HMAC_KEY\`, exclusively held by
an authorized review authority and **not set or generated by this PR**.
If the key or signed proof is absent, the seven-style media must HOLD.
A valid HMAC establishes data integrity and key possession; it alone
**does not prove** that an identified reviewer is independent.
The reviewer identity must be established outside the file through
formal review / trusted approval.

The certificate is date-scoped; tampering with the atlas, cards, narration
file or any video variant invalidates the SHA match. Source JPEGs, review
evidence, publication receipts and protected originals remain immutable.

## Optional senior-readable M2 speech pacing QA (default OFF)

To avoid speeding up the original Hanbok narrator to +31% to meet the
85-second clip limit, a separate **explicit opt-in QA-only** mode is
available:

\`ZODIAC_M2_READABLE_PACE_PILOT=1\`

This mode requires all other strict FLUX male M2 + Hanbok + dog-clarity
flags. It rewrites **only** the calendar cover and end-of-reel CTA, retaining
the exact date, weekday, top-three lucky signs and 사주포춘 reference.
All 12 original daily fortune interpretations in the four main scenes
remain **byte-identical** to those delivered to TTS. It refuses unexpected
cover, CTA or missing scenes instead of changing them by guesswork.

When enabled, the finished narrated six-scene video must meet:
**duration <= 85s** and **Supertonic speaking rate <= +24%**. Any longer
or faster would HOLD instead of delivering a hurried senior-facing video.
These checks are independent of the default legacy video path, which stays
unchanged. The option is **not** set in the operating scheduler.

In the isolated STYLE_01 / 2026-12-07 local M2 experiment, the shortened
cover and closing saved 2.586 seconds at the unchanged +20% pace.
The 12 zodiac readings themselves remained unshortened. The actual QA-only full Hanbok M2 movie on 2026-12-07 finished in
**84.601 seconds at +20%**, twice byte-identically with SHA-256
b6c0fd0fa7b197b31171998fe2bb6b816c70af953a0f4f196974e094dc7909e8.
Nine phone-sized frames showed no overlap or clipping, but small secondary
score fonts still require senior readability review. Each full offline ASR
recognized 11/12 with different ambiguous zodiac words; targeted unprompted
crops recognized the missing ones. This does not establish an independently
certified full 12/12 transcript or human voice signoff. Original atlas
manifests stay PENDING_QA. No HMAC review key, external reviewer credentials
or official release approval were created by the experiment.
